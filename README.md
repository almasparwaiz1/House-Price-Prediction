# House Price Prediction App

A professional Machine Learning web application built with **Streamlit** that predicts house prices based on property features, location intelligence, and advanced preprocessing techniques.

## Features

* Real-time house price prediction
* Interactive Streamlit dashboard
* Location-based price intelligence
* KMeans clustering integration
* Target encoding for address features
* Professional responsive UI
* Machine Learning powered predictions

## Tech Stack

* Python
* Streamlit
* Scikit-learn
* Pandas
* NumPy
* Joblib

## Machine Learning Features

* Feature Engineering
* Target Encoding
* Location Clustering
* Log Transformation
* Data Preprocessing Pipeline
* Regression Model Prediction

## Prediction Inputs

* BHK Number
* Square Footage
* Property Location
* Longitude & Latitude
* Construction Status
* RERA Status
* Property Type
* Posted By Information
